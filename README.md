## نظرة عامة

تطبيق محاسبي وإداري متكامل يعمل **بالكامل دون إنترنت**، صُمم خصيصاً لإدارة محل قطع غيار سيارات تويوتا.  
يتولى تسجيل المبيعات اليومية (كاش، حوالات، محافظ)، الديون الصادرة والواردة، العُهد (قطع عند مهندسين أو زبائن)، المصروفات، وحسابات العمال.  
يقدم تقارير يومية وأسبوعية دقيقة، مع نسخ احتياطي مشفر بالكامل، ونظام تنبيهات ذكي.

---

## الميزات الأساسية

- ✅ تسجيل مبيعات يومي بوسائل دفع متعددة (كاش، حوالات، محافظ)
- ✅ إدارة الديون الواردة (نحن مدينون) والصادرة (نحن دائنون) مع تواريخ الاستحقاق
- ✅ إدارة العُهد (قطع أعطيت لمهندسين أو زبائن) مع تتبع الكميات وتنبيهات التأخير
- ✅ تسجيل المصروفات اليومية مع ربطها بحسابات العمال
- ✅ حساب راتب العامل تلقائياً (الراتب الأساسي - المسحوبات الشهرية)
- ✅ تقرير يومي ختامي مفصل (إجمالي المبيعات، الديون، المصروفات، الصافي)
- ✅ تقارير أسبوعية (أكثر القطع مبيعاً، أكثر الزبائن، مقارنة بالأسبوع السابق)
- ✅ نسخ احتياطي تلقائي مشفر Zip كل ليلة – لا يُحذف تلقائياً (تحذفه أنت يدوياً)
- ✅ تنبيهات محلية للديون المستحقة والعهد المنتهية
- ✅ تطبيقان بصلاحيات مختلفة: مالك (كامل الصلاحيات) وموظف (مبيعات فقط)
- ✅ عمل كامل دون إنترنت (Offline-First)
- ✅ تصدير APK لتثبيته على أندرويد (Galaxy Note 9)

## البنية التقنية

| الطبقة | التقنية المستخدمة | السبب |
|--------|-------------------|-------|
| **إطار الواجهة** | Vue.js 3 (CDN) | تفاعلي، خفيف، سهل التطوير |
| **قاعدة البيانات** | Dexie.js (IndexedDB) | تخزين محلي، استعلامات سريعة، يدعم الفهارس |
| **النسخ الاحتياطي** | JSZip + crypto-js (AES) | ضغط وتشفير الملفات |
| **تصدير الملفات** | FileSaver.js | حفظ الملفات على الجهاز |
| **Service Worker** | sw.js مخصص | تمكين العمل دون اتصال |
| **تغليف APK** | Bubblewrap (Google) | تحويل PWA إلى تطبيق أندرويد أصلي (TWA) |

## قاعدة البيانات

يستخدم التطبيق 10 جداول في IndexedDB عبر Dexie.js:

| الجدول | الوصف |
|--------|-------|
| `parts` | قطع الغيار (كود، اسم، سعر بيع، سعر شراء، فئة) |
| `customers` | الزبائن (اسم، هاتف، عنوان) |
| `engineers` | المهندسون (اسم، هاتف، ورشة) |
| `workers` | العمال (اسم، هاتف، راتب شهري) |
| `invoices` | الفواتير (تاريخ، وسيلة دفع، حالة) |
| `invoiceItems` | عناصر الفاتورة (القطعة، الكمية، السعر) |
| `debts` | الديون (المدين، المبلغ، تاريخ الاستحقاق، حالة التسوية) |
| `custody` | العهد (القطعة، الحائز، الكمية المعطاة، المسترجعة) |
| `expenses` | المصروفات (فئة، بيان، مبلغ، مرتبط بعامل) |
| `workerDraws` | مسحوبات العمال (عامل، تاريخ، مبلغ، ملاحظة) |
| `backups` | بيانات وصفية للنسخ الاحتياطية (تاريخ، اسم، حجم) |

## الصلاحيات

### المالك (Owner)
- صلاحية كاملة على جميع أقسام التطبيق
- الوصول للتقارير اليومية والأسبوعية
- إدارة العمال وحساب الرواتب
- إنشاء وحذف النسخ الاحتياطية
- تعديل الأسعار وحذف الفواتير
- رؤية جميع الديون والعهد

### الموظف (Staff)
- **فقط:** تنفيذ مبيعات جديدة
- لا يمكنه رؤية التقارير أو الأرباح
- لا يمكنه تعديل الأسعار أو حذف الفواتير
- لا يرى الديون والعهد إلا ما سجّله هو شخصياً

## دليل التثبيت والتشغيل

### الطريقة ١: PWA مباشر (أسهل)

1. **رفع الملفات على GitHub Pages:**
   - أنشئ مستودعاً جديداً على GitHub
   - ارفع جميع الملفات (index.html, style.css, app.js, sw.js, manifest.json, icon-192.png, icon-512.png)
   - اذهب إلى Settings → Pages → Source: main branch → Save
   - انتظر دقيقة واحدة ليظهر الرابط

2. **فتح التطبيق على الجوال:**
   - افتح الرابط في متصفح Chrome على Note 9
   - اضغط على ⁝ (القائمة) ← "إضافة إلى الشاشة الرئيسية"
   - سيظهر التطبيق كأيقونة مستقلة

### الطريقة ٢: توليد APK (للتثبيت الكامل)

1. افتح [pwabuilder.com](https://pwabuilder.com)
2. أدخل رابط GitHub Pages
3. اختر "Android" واضغط "Generate"
4. حمّل ملف APK وثبته على الجوال

### الطريقة ٣: Netlify Drop (بديل سريع)

1. اذهب إلى [app.netlify.com/drop](https://app.netlify.com/drop)
2. اسحب مجلد المشروع كاملاً
3. سيُعطى رابط مباشر – افتحه واتبع خطوات PWA

## دليل المستخدم السريع

### ١. تسجيل الدخول
- اختر "المالك" أو "موظف" من القائمة
- أدخل كلمة المرور (الافتراضية: admin123 للمالك، staff123 للموظف)

### ٢. إجراء عملية بيع
- انتقل إلى تبويب 💰 **مبيعات**
- ابحث عن القطعة في حقل البحث (يكتب جزءاً من الاسم أو الكود)
- اختر القطعة من القائمة المنسدلة، واضغط ➕ أضف قطعة
- حدد وسيلة الدفع (كاش، حوالة، محفظة)
- اضغط ✅ إتمام البيع

### ٣. تسجيل دين
- انتقل إلى تبويب 📋 **ديون**
- اضغط ➕ إضافة دين جديد
- املأ البيانات (نوع الدين: لنا / علينا، الطرف، المبلغ، تاريخ الاستحقاق)

### ٤. إدارة العهد (قطع عند مهندس)
- انتقل إلى تبويب 🔩 **عهد**
- اضغط ➕ عهدة جديدة واختر القطعة والمهندس والكمية
- عند استرجاع القطعة، اضغط "إرجاع" بجانب العهدة

### ٥. تسجيل مصروف
- انتقل إلى تبويب 💸 **مصروفات**
- اكتب البيان والمبلغ
- إذا كان المصروف سلفة لعامل: اختر "سلفة عامل" واختر اسمه من القائمة

### ٦. عرض التقرير اليومي
- انتقل إلى تبويب 📊 **تقارير**
- اضغط "عرض تقرير اليوم"

### ٧. عرض التحليل الأسبوعي
- في تبويب 📊 **تقارير**، اضغط "عرض التحليل الأسبوعي"

### ٨. حساب راتب عامل
- انتقل إلى تبويب 👷 **عمال** (للمالك فقط)
- اضغط "حساب الراتب" بجانب اسم العامل

### ٩. نسخ احتياطي
- انتقل إلى تبويب 💾 **نسخ** (للمالك فقط)
- اضغط "إنشاء نسخة الآن" لعمل نسخة فورية
- أو سيُنشئ التطبيق نسخة تلقائية كل ليلة

---

## النسخ الاحتياطي

- **تلقائي:** كل ليلة عند الساعة 12:00 (أو عند أول فتح للتطبيق بعد هذا التوقيت)
- **يدوي:** من تبويب 💾 نسخ
- **التنسيق:** ملف Zip مشفر بكلمة مرور (AES-256)
- **الحذف:** لا يُحذف أي نسخة تلقائياً أبداً. يجب أن تحذفها أنت يدوياً بالضغط على 🗑️
- **موقع الحفظ:** مجلد `Documents/AsholBackup/` على ذاكرة الجوال
