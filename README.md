# نظام محلات طيب علي صالح الأشول – قطع غيار تويوتا

نظام محاسبي كامل لإدارة قطع غيار تويوتا، يعمل بدون إنترنت (PWA).

## الميزات
- مبيعات حرة (تحدد السعر بنفسك)
- إدارة ديون (لنا وعلينا) مع دفاتر فردية
- عهد للمهندسين
- حسابات عمال (رواتب ومسحوبات)
- مخزون ومصروفات
- تقارير وتصدير PDF احترافي
- مزامنة بين الأجهزة

## بيانات الدخول
- المدير: `2005`
- الموظف: `0000`

## التشغيل
1. افتح `index.html` في متصفح حديث.
2. للتثبيت على الأندرويد: اختر "إضافة إلى الشاشة الرئيسية".
